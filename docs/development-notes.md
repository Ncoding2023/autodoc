# 개발 기록

## DOCS 문서 미리보기

- 배경: 작성·수정 화면에서 저장하기 전에 문서 전체 구성을 확인할 수 없었다.
- 변경: 현재 폼 입력값으로 미리보기를 열고, 저장된 문서 상세와 공통 문서 레이아웃을 사용한다.
- 데이터 흐름: 폼 입력값 → 미리보기 데이터 → React 일반 텍스트 렌더링. 미리보기를 열 때 저장 API를 호출하지 않는다.
- 범위: 제목·문서 유형·본문·중요 사항·주의 사항, 줄바꿈과 긴 텍스트 표시, 빈 내용 안내.
- 후속 작업: 템플릿별 서식 반영, 페이지 나눔과 DOCX 생성 결과 연계.

## 확인 대기 사항

- 사용자 제보: 기본 템플릿 선택 후 문서 작성이 진행되지 않는 경우가 있음. 재현 조건과 원인은 아직 확인 전이며 후속 작업에서 조사한다.
- SHEETS 기능은 현재 상태로 보류한다.

## DOCS 양식 규칙과 데이터 구조 · 2026-10-23

- 고정된 본문 입력에서 양식별 항목 입력으로 전환하기 위한 1단계다.
- 항목의 연결 키와 화면 표시 이름을 분리했다. 이름을 바꿔도 키·입력값은 유지한다.
- 양식의 이름 자리(`{{담당자.label}}`)와 내용 자리(`{{담당자}}`)를 연결한다.
- `template_fields`에는 기본 정의, `document_fields`에는 문서별 정의 사본과 입력값을 보관한다.
- 문서에는 작성 시작 시 사용한 원본 양식 파일 ID를 보관한다. 기존 문서·시트 값은 그대로 유지한다.
- 항목별 필수 설정과 항목 추가·배치 편집은 포함하지 않는다.
- 구현 범위는 추가 SQL과 엔티티다. 업로드·API·입력 화면·파일 생성 연결은 후속 단계다.
