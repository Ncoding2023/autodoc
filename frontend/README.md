# AutoDoc Frontend

화면설계서를 참고한 로그인(`/login`)과 회원가입(`/signup`) 화면을 제공한다.
회원가입은 이름, 이메일, 비밀번호, 비밀번호 확인을 입력하고 완료 후 로그인 화면으로 이동한다.
하단의 '팀이 있습니다'를 체크하면 기존 팀 선택 또는 새 팀 이름·설명 입력을 할 수 있다.
체크하지 않으면 개인 회원으로 가입한다. 새 팀 등록과 회원 저장은 한 트랜잭션으로 처리한다.
로그인 화면의 '비밀번호 찾기'는 준비 중 안내 창을 제공하며, 재설정 메일은 발송하지 않는다.
로그인 상태는 HttpSession으로 유지하며 새로고침 시 `/api/auth/me`로 확인한다.
로그인 버튼 위에는 왼쪽 '로그인 유지', 오른쪽 '비밀번호 찾기'를 배치한다.
로그인 유지를 체크하면 HttpOnly 세션 쿠키를 최대 7일 유지한다. 체크하지 않으면
브라우저 세션 쿠키와 30분 비활동 만료를 사용한다. 로그아웃 시 쿠키와 세션을 삭제한다.
서버 재시작으로 세션이 사라지면 다시 로그인해야 한다.
로그인 후에는 `/dashboard`로 이동하고 네이비 공통 메뉴바를 표시한다.
메뉴는 대시보드, 문서 관리, 템플릿 관리, 팀 관리로 구성하며 내 정보와 로그아웃을 제공한다.
1024px 미만에서는 메뉴 버튼으로 탐색 항목을 열고 닫는다.
내부 화면 진입과 메뉴 이동 시 로그인 세션을 확인하고, 세션이 없으면 로그인 화면으로 이동한다.
로그인 완료 후에는 접근하려던 내부 화면으로 돌아간다. 서버 연결 실패 시 재시도 화면을 표시한다.
`/templates`에서는 DOCS/SHEETS 형식별 기본 템플릿을 조회하고 선택할 수 있다.
`/documents/new`는 작성 형식 선택 → 기본 템플릿 선택 → `/documents/new/write` 문서 작성 순서로 진행한다.
형식과 템플릿 ID는 URL에 유지되며 새로고침 시 API 목록을 기준으로 선택을 다시 확인한다.
형식이 다른 템플릿이나 사용자 템플릿은 기본 템플릿 선택 목록에 포함하지 않는다.
템플릿이 없거나 조회에 실패한 경우 안내와 재시도를 제공한다.
`/documents`에서 내 문서를 조회하고 `/documents/:documentId`에서 상세 조회와 삭제를 할 수 있다.
`/documents/:documentId/edit`에서는 제목, 문서 유형과 DOCS 내용을 수정한다.
DOCS는 본문·중요 사항·주의 사항을 저장하고 조회한다. SHEETS는 문서 기본 정보 CRUD를 제공한다.
SHEETS 정보 수정 시 기존 콘텐츠는 보존하며, 열·행 편집은 후속 구현한다.
삭제 확인창을 거쳐 문서와 연결된 데이터를 삭제한다. 서버에서 문서 소유권과 템플릿 작성 형식을 검증한다.
첨부파일, 파일 출력, 사용자 템플릿 관리 등 나머지 업무 화면은 후속 구현한다.

## 실행

```bash
npm install
npm run dev
```

문서 화면의 API 연동 흐름과 실패 처리는 `npm run test:documents`로 검증한다.
이 테스트는 API를 모의 처리하므로 실제 데이터베이스를 변경하지 않는다.

개발 서버는 `/api` 요청을 `http://localhost:8080`으로 프록시한다. 다른 백엔드 주소를 사용하려면 `.env`에 다음 값을 설정한다.

```properties
VITE_API_BASE_URL=/api
```

## 구성

- `src/router`: 화면 URL 라우트와 로그인 접근 제어. 기본 진입 URL은 `/dashboard`이며 로그인하지 않았다면 `/login`으로 이동한다.
- `src/layouts`: 로그인 후 사용하는 공통 메뉴바와 콘텐츠 영역.
- `src/pages`: 인증, 기본 템플릿 선택, 문서 목록·작성·상세·수정 화면과 문서 라우트 처리.
- `src/components`: 작성 형식 선택과 문서 화면 공통 요소.
- 화면 스타일은 Tailwind CSS 4 유틸리티 클래스로 작성한다. `src/styles.css`에는 Tailwind 가져오기, 기본 글꼴과 페이지 전역 설정만 둔다.
- `src/api`: Axios 공통 인스턴스와 도메인별 API 호출 함수.
- `withCredentials: true`: HttpSession 쿠키를 요청에 포함한다.

## 연동 대상

- 회원, 인증, 팀, 템플릿 메타데이터, 문서, SHEETS 열·행 API

관리자 회원 관리, 템플릿 파일, 첨부파일, 파일 생성·다운로드, 미리보기 API는 백엔드가 구현된 뒤 API 모듈을 추가한다.
